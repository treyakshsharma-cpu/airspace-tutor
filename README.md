# 🛸 Airspace Tutor (v1.0.0)
**Digitizing Drone Airspace Compliance & Flight Planning**

Airspace Tutor is a "Regulator-Grade" interactive platform designed to bridge the gap between complex UK Civil Aviation Authority (CAA) policy and digital flight operations. This project translates over 70 pages of regulatory frameworks into a type-safe, interactive "Duolingo-style" learning engine.

## 🏗️ The Engineering Bridge
Developed as part of my **BEng in Aerospace Engineering with Pilot Studies (UWE Bristol)** and informed by active industrial application at **Carbon Magics Ltd**, this repository digitizes:

* [cite_start]**The RPC-L1 Standard:** A risk-based modern qualification that serves as a ladder to BVLOS (Levels 2–4)[cite: 171, 172].
* [cite_start]**PDRA-01 Compliance:** Enforcing mandatory 50m separation distances and the 120m (400ft) altitude cap[cite: 433, 439].
* [cite_start]**Operational Readiness:** Tracking the transition from legacy GVC certifications to future-proof UK SORA standards[cite: 171, 384].

## 🛠️ Key Features
* [cite_start]**Interactive Flight Sandbox:** Real-time validation of mission parameters against CAP 722H constraints[cite: 431, 440].
* [cite_start]**Automated Cost Estimator:** Real-time setup budgeting based on the 2025/2026 CAA Scheme of Charges (£11.79 Operator ID, £500 PDRA-01 fees)[cite: 47, 60, 675, 731].
* [cite_start]**Compliance Dashboard:** A visual tracker for Phase 1 Operational Readiness, including Flyer IDs, Insurance (EC 785/2004), and GVC/RPC-L1 status[cite: 126, 222, 231].
* [cite_start]**Scenario Simulations:** Gamified modules for high-risk operations including roof surveys, industrial mapping, and infrastructure inspections[cite: 436, 482].

## 🚀 Tech Stack
* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS & Shadcn UI
* **Logic:** TypeScript Regulatory Engine (Validated against CAP 722 and PDRA-01)
* **Deployment:** Vercel (CI/CD via GitHub Actions)
